# wireless-powertrain-control

배터리 BMS와 모터 컨트롤러(Motor Controller)를 무선으로 모니터링·제어하는 프로젝트입니다.

## 범위 (초안)

- BMS / 모터 컨트롤러와의 차량 내 통신 (예: CAN)
- 차량 ↔ 피트 간 무선 링크 (방식 TBD)
- 피트 측 모니터링 및 제어 인터페이스
- 안전: 무선 제어 명령에 대한 인증, 통신 두절 시 페일세이프 동작
