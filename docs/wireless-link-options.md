# 차량 → 피트 무선 링크 비교 (최대 300 m)

## 필요 대역폭 추정

| 데이터 | 샘플링 | 크기 | 대역폭 |
| --- | --- | --- | --- |
| 서스펜션 포텐셔미터 4ch | 500 Hz | 4 × 2 B | 4.0 kB/s |
| IMU 6축 | 500 Hz | 6 × 2 B | 6.0 kB/s |
| GPS | 10–25 Hz | ~40 B | ~1.0 kB/s |
| 지상고 4ch | ~20 Hz | 4 × 2 B | 0.2 kB/s |
| CAN (BMS + 모터 컨트롤러) | 버스 부하 따라 | 16 B/프레임 | 5–20 kB/s |
| **합계** (+프레임 오버헤드) | | | **약 20–35 kB/s (160–280 kbps)** |

→ **전체 원본을 실시간으로 보내려면 수백 kbps 급 링크**가 필요합니다.
LoRa 같은 저속 링크로는 다운샘플한 요약 데이터만 보낼 수 있고, 원본은 SD + 사후 동기화로 확보합니다.

## 후보 비교

| 방식 | 300 m | 대역폭 | 장점 | 단점 / 주의 |
| --- | --- | --- | --- | --- |
| **휴대폰 핫스팟 + 차량 서버** (제안안) | ✗ 어려움 | 수 Mbps | 구성 간단, 별도 하드웨어 불필요 | 휴대폰 핫스팟 AP의 실사용 거리는 수십 m 수준. 피트 노트북이 그 AP에 직접 붙어야 하므로 300 m 에서 끊김. 폰 발열/배터리, 차체(카본)에 의한 차폐 |
| **휴대폰/LTE 모뎀 → 클라우드(MQTT) ← 피트** | ✓ (거리 무관) | 수 Mbps | 거리 제한 없음, 대회장 어디서나 | 통신사 CGNAT 때문에 **차량에 서버를 열고 외부에서 접속하는 구조는 불가** → 차량이 브로커로 *밀어내는* 구조여야 함. 대회장 인파로 셀 혼잡, 지연 50–500 ms 변동, 데이터 요금 |
| **2.4 GHz Wi-Fi + 피트 측 고이득 안테나** | ✓ (가시거리) | 수 Mbps | 대역폭 충분, UDP 그대로 사용, 부품 저렴 | 피트 AP를 마스트 위에 지향성/섹터 안테나로 설치해야 함. 차량 쪽은 외장 안테나(ESP32 u.FL 모델 등). 다른 팀 Wi-Fi 와 간섭 |
| **ESP-NOW Long Range 모드** | ✓ (가시거리) | ~250–500 kbps | AP 불필요, 저지연, ESP32 끼리 바로 통신 | Espressif 전용. 대역폭이 원본 전체에는 빠듯 |
| **LoRa (KR920, SX1262 등)** | ✓✓ (수 km) | ~5–20 kbps | 매우 안정적, 장애물에 강함 | 대역폭 매우 낮음 → 요약 데이터·하트비트 전용. 국내 920.9–923.3 MHz 대역·출력·LBT 규정 준수 |
| **Wi-Fi HaLow (802.11ah, 900 MHz)** | ✓✓ (~1 km) | 1–10 Mbps | 거리와 대역폭 모두 확보, IP 기반 | 모듈 가격, 레퍼런스 적음. 국내 대역 지원 모듈인지 확인 |
| **nRF24L01+ PA/LNA** | △ | 250 kbps–2 Mbps | 저렴 | 모듈 품질 편차 큼, 실전 안정성 낮음 |

> 해외용 900 MHz 모듈(XBee 900HP 등 902–928 MHz)은 국내 대역과 달라 사용 불가할 수 있습니다. 무선 모듈은 KC 인증/국내 대역 지원 여부를 먼저 확인하세요.

## 추천: 이중 링크 + SD 백업

```
            ┌── 주 링크: 2.4 GHz Wi-Fi(UDP)  또는  LTE→MQTT  ── 원본 실시간 + 백필
 차량 ──────┤
            └── 보조 링크: LoRa KR920 ── 하트비트, 핵심 요약값(SOC, 온도, 속도, 폴트)
 SD 카드 ── 모든 프레임 원본 (사후 동기화)
```

- 주 링크가 끊겨도 LoRa 로 **차량 상태와 "어디까지 보냈는지(최신 seq)"** 를 계속 받으므로, 피트는 손실 구간을 정확히 알 수 있습니다.
- 주 링크가 복구되면 NACK → 백필로 구멍을 메웁니다.
- 끝까지 못 받은 구간은 세션 후 SD 동기화(피트 Wi-Fi 근처에서 자동 업로드 또는 카드 회수)로 채웁니다.
- 프로토콜이 링크 독립적이므로, 초기에는 가장 구하기 쉬운 **ESP32 + 외장 안테나 Wi-Fi** 로 시작하고, 필요하면 HaLow/LTE 로 교체할 수 있습니다.

## 결정 전에 할 일: 실측

실제 트랙(또는 비슷한 운동장)에서 후보 링크별로 **50 m 간격 RSSI / 패킷 손실률 / 지연**을 측정하세요.
AERO 프레임에 seq 가 있으므로 `GapTracker` 로 손실률을 바로 계산할 수 있습니다.
차량에 장착한 상태(카본 차체, 모터/인버터 노이즈)에서 측정해야 의미가 있습니다.
